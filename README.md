# Agents: A tutorial on building agents in Python

This is the companion repo for this blog post:

[Agents: A tutorial on building agents in Python](http://programmer.ie/post/agents/)


Some example notebooks on agents

- These examples all use [Ollama](https://github.com/ollama/ollama) and 
[smolagents](https://github.com/huggingface/smolagents) to build these examples.

|Notebook|Description|  
|[Introduction](notebooks/smolagents.ipynbs)| Introduction simple agent example |  
|[Query Database](notebooks/sql.ipynb)| An agent that will query a database|   
|[Generate python code](notebooks/numbers.ipynb)| We call an agent to generate a python function and execute it.|   
|[Using Tools](notebooks/tools.ipynb)]| How to use tools in agents.|  
|[Online Picture search](notebooks/picture_getter.ipynb)|Combine agents to get an image from the internet|  
|[Using code in an agent](notebooks/webpage_title.ipynb)| An example showing how we can use code to get a job done. |  
|[Multiple Agent Collaboration](notebooks/multi_agent.ipynb)| A manger agent controls agents.|
